# ПрорАКТ 360 · карточка Telegram-бота

## Название

**ПрорАКТ 360**

Смысл: «прораб + акт», а `360` подчёркивает полный цикл — смета, объект,
скрытые работы, акты, оплаты и кабинет заказчика.

## Короткое описание

Сметы, акты, оплаты и фотоотчёты по объекту — прямо в Telegram.

## Полное описание

Цифровой помощник мастера отделочных работ. Собирает сметы и акты с телефона,
подставляет цены из прайса, считает оплаты и долги, хранит фото скрытых работ и
показывает заказчику понятный прогресс по его объекту.

## Оформление в BotFather

1. `/setname` → `ПрорАКТ 360`.
2. `/setabouttext` → вставить короткое описание выше.
3. `/setdescription` → вставить полное описание выше.
4. `/setuserpic` → загрузить `proakt360-telegram-avatar.png` из этой папки.
5. После развёртывания перезапустить сервис: приложение само обновит кнопку
   меню на `🧰 ПрорАКТ 360`.

Аватар специально сделан без мелкого текста и с безопасными полями под круговую
обрезку Telegram.
